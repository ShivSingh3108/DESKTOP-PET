
# DESKTOP PET
## About 
I created a Cybersecurity themed Desktop pet for windows using godot for stardance event of Hackclub.
<img width="923" height="255" alt="Screenshot (41)" src="https://github.com/user-attachments/assets/35d6e545-4fcc-4ada-b8a2-637bd56e0243" />
## Features
* 2 Pets - It has 2 pets named: Malware and Firewall and you can get one at random, you can also reroll.
* gdshaders -Flash when you drag one the Malware pet.
* Right click Menu - Shows a Menu when Firewall pet is right clicked.
* Label and Timer - Used for Lore, idling and for cybersecurity info  .
* Click and Double Click - Click starts a Label and double click opens website.
* Animation and Sprite -Has Animation for idling, movement and resting. All sprites are made by me.

## Built With
* GODOT(GDscript)

Its still not perfect , I will be adding more features in future.
